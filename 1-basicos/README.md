# Nivel 1 · Básicos

15 ejercicios para coger soltura con lo esencial de JavaScript: funciones, condiciones, bucles, arrays y objetos.

## Cómo hacerlo

1. Abre `Tests.html` en el navegador. Verás todos los tests en rojo.
2. Abre `src/ejercicios.js`. Cada bloque de comentarios es un ejercicio: resuélvelo justo debajo.
3. Guarda y refresca `Tests.html`. Los tests del ejercicio resuelto se pondrán en verde.

Cuando esté todo en verde, pasa a [`2-funcionales`](../2-funcionales).
