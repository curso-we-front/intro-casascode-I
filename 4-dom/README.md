# Nivel 4 · DOM

15 ejercicios para que JavaScript lea y modifique la página: textos, estilos, clases, crear elementos y responder a eventos.

## Cómo hacerlo

1. Abre `Tests.html` en el navegador. Verás todos los tests en rojo.
2. Abre `src/ejercicios.js`. Cada bloque de comentarios es un ejercicio: escribe la función justo debajo.
3. Guarda y refresca `Tests.html`. Los tests del ejercicio resuelto se pondrán en verde.

No necesitas crear ningún HTML: cada test crea por su cuenta los elementos que indica el enunciado (con su id o su clase), llama a tu función y comprueba que la página ha cambiado como se pedía. Por eso, busca siempre los elementos **dentro** de tu función con `document.querySelector` o `document.querySelectorAll`.
