# Nivel 2 · Funcionales

15 ejercicios para dejar de usar bucles `for` y trabajar con arrays como en el día a día: `map`, `filter`, `find`, `reduce`, `some`, `every` y `sort`.

## Cómo hacerlo

1. Abre `Tests.html` en el navegador. Verás todos los tests en rojo.
2. Abre `src/ejercicios.js`. Cada bloque de comentarios es un ejercicio: resuélvelo justo debajo, **sin bucles `for`**.
3. Guarda y refresca `Tests.html`. Los tests del ejercicio resuelto se pondrán en verde.

Cuando esté todo en verde, pasa a [`3-css`](../3-css).
